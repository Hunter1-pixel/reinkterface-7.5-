# CLAUDE.md

Guidance for working on this fork.

## What this is

ESP32-S3 firmware for a standalone e-ink PC stats display, based on Valve's
Inkterface protocol and adapted for the TRMNL 7.5" (OG) DIY Kit.

Hardware:
- Board: Seeed XIAO ePaper Display Board / EE04
- Panel: Good Display GDEY075T7, 800x480, UC8179 / GD7965 controller
- Battery: TRMNL kit battery read through GPIO1 with GPIO6 load-switch enable

The host-side app is Valve's separate Inkterface app. Keep the BLE UUIDs and
packed payload layouts compatible with that host unless both sides are changed.

## Commands

Build system is PlatformIO:

```sh
pio run
pio run -t upload
pio device monitor
```

There are no unit tests or linter configured; `src/main.cpp` is effectively
the whole firmware.

## Firmware Notes

- Dashboard redraws are full-panel only to avoid stale regions and ghosting.
- Idle mode draws the Gaben sleep bitmap, then hibernates the panel.
- On reconnect or host writes, the firmware exits idle and schedules a full
  dashboard redraw.
- Text drawing is hand-rolled with fixed pixel budgets. Keep header lines and
  tile title/value lanes bounded so strings cannot overlap.
- Bitmaps in `src/*.h` are generated byte arrays and should be regenerated from
  source images rather than hand-edited.
